# 🐴 年賀AR馬 (New-Year-Horse)

### *「年賀状をかざすだけで、2026年の馬が走り出す。」*
> 年賀状そのものをARマーカーとして活用した、WebブラウザだけでARを体験できるアプリケーションです。

## 📖 制作背景 (Background)

毎年、友人へ手作りデザインの年賀状を送っています。
2026年は午年ということで、**「年賀状から馬が走り出す」** ARギミックを添えることにしました。

当初はQRコードのみでAR起動を試みましたが、ARの位置決めには別途「マーカー画像」が必要であることが判明。
専用マーカーを印刷すると、こだわってデザインした年賀状のビジュアルが崩れてしまいます。

そこで発想を転換し、**年賀状のイラストデザインそのものをマーカー画像として登録**する方針に切り替えました。
QRコードを読み込んだあと、年賀状にカメラをかざすだけで馬が出現する、シームレスな体験を実現しています。

---

## 🎯 設計思想 (Design Philosophy)

### 1. 「年賀状を壊さない」AR設計
一般的なARでは、専用のマーカーシートを別途用意する必要があります。
本作では MindAR.js の Image Tracking 機能を使い、**年賀状そのものをトラッキング対象**として登録することで、追加の印刷物なしにARを成立させました。デザインの完成度を保ちつつギミックを追加するという、送り手のこだわりを体験として届けます。

### 2. インストール不要・URLだけで体験できる
受け取った相手がアプリをインストールする手間は一切不要です。
QRコードをスキャンしてブラウザを開くだけで、その場でARを体験できます。

### 3. 4頭の馬が異なる速度で周回する演出
年賀状の上で馬を1頭走らせるだけでは単調になります。
本作では90度ずつずらした4頭の馬を同時に走らせ、それぞれの `timeScale`（0.7 / 1.0 / 1.5 / 2.5）を意図的にバラバラにすることで、馬同士が追い越したり離れたりするランダム感のある疾走シーンを作り出しています。さらに、中央では豪華できらびやかにデザインされた「2026」の文字が10秒1周でゆっくり回転し続け、AR空間全体が動き続ける「生きたシーン」となっています。

## 📁 ファイル構成 (File Structure)

```
New-Year-Horse/
├── index.html       # ARシーン本体（A-Frame + MindAR）
├── horse.glb        # 3D馬モデル（GLBフォーマット）
├── targets.mind     # MindAR用トラッキングデータ（年賀状の写真をコンパイルして生成）
└── text.png         # AR空間で回転表示される「2026」の文字グラフィック
```

> ※ 年賀状のイラスト画像そのものはリポジトリには含まれていません。`targets.mind` はその年賀状をMindAR Image Target Compilerで処理したデータです。

## 🔧 工夫した点 (Implementation Notes)

### マーカー登録フロー
自作の年賀状をMindAR の Image Target Compiler に通すことで `targets.mind` を生成しています。このファイルを読み込むことで、カメラが年賀状を認識した瞬間に3Dオブジェクトが起動します。なお年賀状のイラスト画像自体はリポジトリには含まれていません。

### 馬の姿勢・接地調整
配布元の GLB モデルはデフォルト状態では横倒しになるため、`rotation="90 0 0"` で起こしています。また、馬の足が年賀状の紙面にめり込んだり浮いたりしないよう、`position="0 0.4 0"` の Y 値を繰り返し微調整して自然な接地感を出しています。

### 4頭の馬が異なる速度で円を描いて走る
馬を1頭だけ走らせるのではなく、90度ずつ回転オフセットを付けた**4頭の馬**が年賀状の中心を囲むように周回する構成にしました。さらに各馬の `animation-mixer` の `timeScale` を `0.7 / 1.0 / 1.5 / 2.5` とバラバラに設定しており、同じ動きがループするだけでなく、馬同士が次第に追い越したり離れたりするカオスな疾走感が生まれます。

### 「2026」の文字が年賀状の上で回転する演出
AR空間の中央では、豪華できらびやかにデザインされた「2026」の文字グラフィック（`text.png`）が10秒で1周するアニメーションで年賀状の上を回転し続けます。馬の周回と組み合わさることで、静的なARではなく「動き続けるシーン」としての演出に仕上げています。

## 🚀 体験方法 (Getting Started)

### 受け取った方へ
1. 年賀状に印刷された **QRコード** をスキャンする。
2. ブラウザが開いたら、カメラへのアクセスを許可する。
3. **年賀状全体** にカメラを向ける。
4. 馬が走り出します🐴

### 開発者向け（ローカル確認）
`index.html` をローカルのHTTPSサーバーで配信する必要があります（カメラAPIはHTTPSが必須）。

```bash
# npx serve を使う場合
npx serve .

# Python の場合（HTTPSが必要なためngrok等と組み合わせる）
python -m http.server 8000
```

## 📝 制作メモ (Retrospective)

年賀状という「印刷物」とデジタルARを、追加コストなしに融合させることが本作の核心です。

デザインを壊さずにARを成立させるという制約が、「年賀状そのものをマーカーにする」という発想を生みました。
さらに「馬を1頭走らせるだけ」に留まらず、90度ずつずらした4頭を異なる速度で周回させることで、毎回違う動きに見える予測不能な疾走シーンが生まれました。回転角・接地高さ・各馬の速度の調整は地味ながら最も時間をかけた工程であり、AR上でいかにリアルな「存在感」を出すかへのこだわりが詰まっています。
